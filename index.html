Política de Privacidad de Seraph

Transparencia, seguridad y protección de datos en Discord

✓ Actualizado para la Verificación de Desarrolladores de Discord

1. Introducción

El bot Seraph está diseñado para brindar seguridad, prevención de spam y sistemas de verificación Anti-Alt en comunidades de Discord. Respetamos tu privacidad y estamos comprometidos con la protección de los datos de los usuarios conforme a las Políticas para Desarrolladores y Términos del Servicio de Discord.

2. Información que Recopilamos

Para operar el sistema de verificación y protección de servidores, Seraph procesa los siguientes datos técnicos:

  • Identificadores de Discord: ID de Usuario (user_id) e ID del Servidor (guild_id).
  • Datos de Conexión Técnica: Dirección IP (analizada mediante APIs de reputación únicamente para detectar VPN, Proxies o Datacenters) e información del User-Agent del dispositivo.
  • Huella Digital Técnica (Fingerprint): Hash anónimo generado a partir de parámetros técnicos del navegador para evitar la proliferación de cuentas secundarias en el servidor.

3. Uso de la Información

La información recopilada se utiliza de forma estricta y exclusiva para los siguientes fines:

  • Validar la autenticidad del usuario e impedir el acceso de cuentas automatizadas o sospechosas.
  • Asignar y remover roles de acceso en Discord automáticamente al completar la verificación.
  • Permitir a los administradores del servidor auditar posibles evasiones de sanciones mediante comandos como /alts y /status.

Garantía de Privacidad: Seraph NO vende, NO alquila ni comparte datos con terceros para fines comerciales o publicitarios.

4. Almacenamiento y Seguridad de Datos

Todos los datos se almacenan de forma segura en bases de datos con accesos restringidos y encriptados. Las fichas de verificación de la sesión web (tokens) expiran automáticamente en 30 minutos sin dejar rastros utilizables.

5. Eliminación de Datos y Derechos del Usuario

Cualquier usuario o administrador de un servidor puede solicitar la revocación y eliminación inmediata de sus registros de verificación utilizando el comando oficial de administración /unverify dentro de Discord o contactando directamente con el equipo de soporte.

6. Contacto y Soporte

Si tienes preguntas sobre esta Política de Privacidad o sobre el tratamiento de tus datos, puedes contactarnos a través del servidor oficial de soporte en Discord.
